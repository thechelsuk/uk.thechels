##  About

Hiyd is a jekyll companion app, that makes writing jekyll/markdown blog posts from iOS easy; saving to iCloud ready for further dev work, or publish directly to GitHub using up to 5 different configs/PAT tokens.

## What's Changed

- Feat auth support
- Feat front matter manage
- Feat add github publishing management
- Stop claiming ownership of Markdown/text/folder file types
- Remove the redundant search tab from ContentView
- Fix the "System" app-icon option and a StoreManager leak
- Cut GitHub publish from multiple API calls
