## About

SecOpsNews gathers security news, government advisories, critical CVEs, data breaches and cloud outages from more than 30 RSS and Atom feeds into GitHub issues, and builds the dashboard at [secops.thechels.uk](https://secops.thechels.uk) from them.

## What's Changed

- Add Cloudflare Radar's critical CVE feed, with its own Critical CVEs panel on the dashboard
- Publish every feed as OPML at secops.thechels.uk/feeds.opml, rebuilt automatically when a feed is added
- Add a subscribe page for getting the rundown in Slack, Microsoft Teams, a feed reader or GitHub
- Fix the Cloudflare blog feed, and show its posts as blog posts, not status notices
- Remove the Politico feed, which no longer worked
