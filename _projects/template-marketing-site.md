A GitHub template repository for a static HTML and CSS marketing site for an app, deployed to GitHub Pages as it is, with no Jekyll build.

It comes with the deploy workflow, a weekly link checker, dependency review and releases from my [shared workflows](https://github.com/thechelsuk/workflows), Dependabot for actions, the community files, an MIT licence, a `security.txt`, `robots.txt`, `sitemap.xml` and `llms.txt`.

- Use the template to create a new repo.
- Set the `CNAME` and the `site_host` in the link checker to the site's host.
- Fill in the placeholder page with the app's name, description and App Store link.
- Set GitHub Pages to deploy from GitHub Actions, and add the custom domain.
- Start a commit's first line with `release:` to tag a release.
