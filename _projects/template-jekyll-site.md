A GitHub template repository for a minimal working Jekyll site, deployed to GitHub Pages with GitHub Actions.

It comes with the deploy workflow, a weekly link checker, dependency review and releases from my [shared workflows](https://github.com/thechelsuk/workflows), Dependabot for actions and gems, the community files, an MIT licence and a `security.txt`.

- Use the template to create a new repo.
- Set the `CNAME` and the `site_host` in the link checker to the site's host.
- Update `_config.yml` with the site's title, description and URL.
- Replace the placeholder home page and layout with your own.
- Set GitHub Pages to deploy from GitHub Actions, and add the custom domain.
- Start a commit's first line with `release:` to tag a release.
