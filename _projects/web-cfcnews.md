Chelsea FC's latest news as a fast, lo-fi page and an [Atom feed](https://cfcnews.thechels.uk/feed.xml). The page lists each headline with its date and a link to the story on chelseafc.com. It's about 4 KB, has no JavaScript, works on a phone and follows light or dark mode.

I made it for my own reading and accessibility needs. It's unofficial, and it isn't connected to Chelsea FC.

A Python script reads Chelsea's news listing and writes the feed every 5 minutes on GitHub Actions, and the page is built from the feed. Hosted on GitHub Pages. The code is [on GitHub](https://github.com/thechelsuk/uk.thechels.cfcnews).
